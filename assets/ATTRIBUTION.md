# Asset attribution

Every file in `public/assets/` and `public/favicon.svg` must have a provenance
entry in `assets/provenance/` (see `.agents/skills/asset-license-audit/SKILL.md`).
Assets whose licence requires attribution (e.g. CC BY 4.0) are credited here,
using the exact wording the author asks for.

Full provenance records are maintained in `assets/provenance/own-work.yml`.
