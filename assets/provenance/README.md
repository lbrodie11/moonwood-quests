# Asset provenance

One YAML file per source (`kenney.yml`, `quaternius.yml`, `game-icons.yml`,
`own-work.yml`, …). Each entry records where an asset came from and what rights
we have, so the answer never depends on memory. See `_template.yml`.

Suggested sources from the research:

| Source | Licence posture | Best use |
|---|---|---|
| Kenney (kenney.nl/assets) | Many packs CC0 | UI, icons, prototypes |
| Quaternius (quaternius.com) | Free packs CC0 | Stylised low-poly 3D |
| Poly Haven (polyhaven.com) | CC0 | Textures, HDRIs |
| game-icons.net | Mixed CC BY 3.0 / CC0 | Spell and inventory icons (attribute!) |
| SIL Andika font | OFL 1.1 | Literacy-friendly typeface; self-host in `public/assets/fonts/` |
